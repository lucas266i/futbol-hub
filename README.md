# Fútbol Hub

Mini-directorio web de enlaces oficiales del fútbol internacional.

## Incluye
- FIFA y las 6 confederaciones continentales.
- Directorio de federaciones nacionales.
- Búsqueda por país o federación.
- Filtro por continente/confederación.
- Enlaces oficiales y enlace general de FIFA.
- Diseño responsive.
- Sin backend ni dependencias externas.

## Publicación
El proyecto es estático y puede publicarse con GitHub Pages usando la rama `main` y la carpeta raíz.

Repositorio: https://github.com/lucas266i/futbol-hub
